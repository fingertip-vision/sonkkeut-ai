# 손끝길 core — F-05 화면 구조화 · F-07 버튼 순서 계획 (담당 노현석)

파이썬 프로토타입. 규칙이 굳으면 안드로이드(Kotlin)로 옮긴다. 실행은 `../ocr/.venv` 파이썬.

| 파일 | 역할 |
|---|---|
| `screen_struct.py` | **F-05** 요소(F-03)+문자(F-04) → 화면 구조 JSON. 화면 종류 분류, 뒤로가기 재분류, 장바구니 줄 수량 붙이기, 합계, 직전 화면과 차이 |
| `planner.py` | **F-07** 의도+화면 구조+진행 상태 → 다음 버튼 1개와 예고 문장. 메뉴명으로 탭 추측, 본 메뉴 기억, 인식 실수 대비(느슨한 매칭·+/− 위치 추정·한 번 더 읽기). `after_press` 는 F-10 대역 |
| `kiosk_sim.py` | 누르면 넘어가는 가짜 키오스크 3종(A 세로 카드·B 가로 목록+아이스 별도 메뉴·C 가로 카드+장바구니 패널) |
| `run_sim.py` | 주문을 끝까지 자동 진행하며 측정. `--perception gt`(인식 완벽) / `ocr`(화면 열화 → OCR v2) |

## 결과 (2026-10-03, 90주문 = 브랜드별 30)
| 인식 | 화면 종류 분류 (F-05, 기준 95%) | 다음 버튼 정답률 (F-07, 기준 95%) | 주문 성공 |
|---|---|---|---|
| 정답 글자 | 100% | 98.5% | 100% |
| 실제 OCR(흐림 섞음) | 99.9% | 95.6% | 91.1% |

- 다음 버튼 '정답' = 시뮬레이터 내부 상태로 구한 맞는 버튼 집합에 드는 것. 탭을 추측해 탐색하는 단계는 정답 집합 밖이면 오답으로 센다.
- 주문 성공 = 결제 화면 도달 + 장바구니가 의도와 정확히 일치.
- 남은 실패는 주로 장바구니 수량(숫자·+/− 인식). 진짜 F-03 은 아직 없어 요소 박스는 정답을 썼다.

## 팀과 맞출 것
- 요소 종류: 명세(버튼·메뉴·가격·탭·뒤로가기)에 더해 `cart_item`(장바구니 줄)·`text`(일반 글자: 수량 숫자, 안내문)·`title` 가 필요하다 → 김우주(F-03)

# F-06 후보 고르기 · 다시 묻기 · 가까이 안내 (2026-10-04, `voice_order.py`)
- Whisper 빔 상위 5개 문장을 모두 규칙으로 풀고, 같은 의도로 풀리는 후보 확률을 합쳐 **확신**을 낸다. 메뉴명이 메뉴판과 정확히 맞을수록 가산
- 확신 < 0.7 이면 추측하지 않고 다시 묻는다. 소리 크기로 시끄러움을 추정해 "휴대폰을 입에 더 가까이" 안내, 작으면 "조금 더 크게"
- 시작 안내 자체를 "휴대폰을 입 가까이 대고 주문을 말씀해 주세요"로
- 없는 메뉴 제안: 같은 종류(과일 음료·커피·차·디저트)·같은 재료 우선 (망고주스 → 망고스무디)

주문 100개(TTS, Whisper v3) — 맞게 확인 / 틀리게 확인 / 다시 물어도 실패. 다시 물었을 때 2차 시도는 시뮬레이션:
'다시 말함' = 같은 소음 세기·다른 소음 조각, '가까이 말함' = 폰 절반 거리 → 목소리 +6dB 가정(실측 아님)

| 조건 | 기존(후보 1개, 항상 확인) | 기준 0.7: 1번 시도 | + 다시 말함 | + 가까이 말함 |
|---|---|---|---|---|
| 깨끗 | 90 / 10 / 0 | 87 / 8 / 5 | (같은 음성뿐이라 측정 불가) | – |
| 소음 15dB | 87 / 13 / 0 | 83 / 11 / 6 | 87 / 11 / 2 | 85 / 11 / 4 |
| 소음 5dB | 65 / 35 / 0 | 60 / 26 / 14 | 69 / 30 / 1 | 69 / 28 / 3 |
| 소음 5dB, 기준 0.8 | – | 57 / 20 / 23 | 68 / 26 / 6 | **73 / 24 / 3** |

- 후보 투표만으로는 기존과 같다(빔 후보들이 대부분 같은 의도로 풀림). 효과는 **확신이 낮을 때 다시 묻는 데서** 나온다: 시끄러운 곳에서 틀린 확인 35 → 24~28
- 깨끗한 곳의 남은 틀림(7~10개)은 확신이 높은 채로 틀리는 경우(예: '여기서 먹고 가요'를 놓쳐 매장/포장 누락) → 확인 질문 단계에서 잡아야 함
