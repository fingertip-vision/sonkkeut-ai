# 손끝길 M5 음성인식 — Whisper 어르신·매장소음 파인튜닝 (담당 노현석)

SDK 0.1.4 / 앱 0.1.8: 매장별 SQLite 메뉴 검색 보정과 5개 후보 디코딩, 녹음 완료 버튼을 추가했습니다. [새 성능 평가·DB·프론트 연결](../docs/speech-menu-rag.md)을 확인하세요. 가중치 재학습은 없으며 소음 환경의 실사용 성능은 미달입니다.

현재 앱 통합과 모델 설치·프론트 계약은 [`../docs/unified-ai.md`](../docs/unified-ai.md)를 따른다.
Android는 CTranslate2 ARM64 RUY JNI를 사용한다. 아래는 원본 학습·평가 기록이며 실제 기기 성능
검증과 구분한다.

별도 venv(`.venv`: torch 2.14 cu126, transformers 5.18, faster-whisper). GPU 추론은 torch/lib 의 cuBLAS·cuDNN 을
`os.add_dll_directory` 로 빌려 쓴다(그냥은 cublas64_12.dll 없음 오류).

| 파일 | 역할 |
|---|---|
| `prep_sd.py` | 568 소음 속 실제 대화(_SD) → 발화 단위(학습 16,567 / 평가 1,210, 녹음 단위 분리) |
| `prep_data.py` | AIHub zip → 16kHz 변환. 94 키오스크 노인 검증 2,000(화자 69)·학습 57,568(화자 55), 568 카페 업소소음 소음만(_SN) 학습 300·평가 60 |
| `train_whisper.py` | HF 파인튜닝. 소음 60% 섞기(SNR 0~20). `--freeze-decoder` 인코더만, `--resume last` 이어서 |
| `eval_asr.py` | 어르신 검증 앞 600개(체크포인트 선택엔 1400~1699 사용) × 깨끗/매장소음 10·5dB, CER. 숫자→한글 읽기 정규화, **학습 대본에 없는 문장만**(168개) 따로 |
| `transcribe_utt100.py` | core 주문 100개 TTS 받아쓰기(힌트 있음/없음) → core/runs |
| `run_v1.sh`, `run_v2.sh` | 도구 백그라운드 30분 제한을 피해 `Start-Process` 로 띄우는 전체 실행 |

## ★ 채택: `ct2/whisper-elder-v3` (2026-10-03)
v3 = 디코더 고정 + 어르신 키오스크 음성(매장소음 섞기) + **실제 매장소음 속 실제 대화** 1에폭, 실제 소음 대화로 체크포인트 선택

실제 매장 소음 속 대화 시험(학습 안 쓴 녹음 40개·600문장) CER: 튜닝 전 13.6 / v2 14.1 / **v3 8.1**
→ 깨끗한 음성에 소음을 덧붙인 학습(v2)은 실제 소음 속 발화에 효과가 없었다. 실제 소음 속 음성을 넣어야 했다.

| 모델 | 어르신 대본 밖 문장 CER 깨끗/10dB/5dB | 주문100 의도(힌트) | 주문100 의도(힌트 없음) |
|---|---|---|---|
| 튜닝 전 | 12.0 / 22.7 / 36.1 | 98 / 91 / 47 | 91 / 78 / 34 |
| v2 | 3.5 / 7.1 / 12.0 | 96 / 88 / 59 | 87 / 80 / 42 |
| **v3** | 3.8 / 7.4 / 12.4 | **97 / 90 / 60** | **92 / 85 / 47** |

## 결과 (v1·v2)
어르신 키오스크 음성 CER (전체 / 학습 대본에 없는 문장)

| 모델 | 깨끗 | 매장소음 10dB | 매장소음 5dB |
|---|---|---|---|
| Whisper small (튜닝 전) | 11.3 / 12.0 | 20.3 / 22.7 | 32.2 / 36.1 |
| v1 (전체 학습 2에폭) | 2.5 / 8.4 | 3.8 / 11.5 | 5.7 / 14.8 |
| **v2 (인코더만 1에폭)** | **2.1 / 3.5** | **4.2 / 7.1** | **8.5 / 12.0** |

주문 100개(TTS) 의도 정확도, 메뉴명 힌트 있음: 깨끗 / 소음15dB / 소음5dB

| 모델 | 힌트 있음 | 힌트 없음 |
|---|---|---|
| 튜닝 전 | 98 / 91 / 47 | 91 / 78 / 34 |
| v1 | 76 / 77 / 33 | 53 / 41 / 20 |
| **v2** | **96 / 88 / 59** | 87 / 80 / 42 |

- v1 은 카페 외래어를 잊고 힌트를 엉뚱하게 끼워 넣었다(데이터가 일반 키오스크 대본이라 디코더가 쏠림) → **v2(디코더 고정)를 쓴다**: `ct2/whisper-elder-v2`
- 지연(GPU, Titan RTX): 약 0.15~0.3초. 폰(whisper.cpp)에서는 다시 재야 한다.
- 검증 문장 71%가 학습 대본과 같다 → '대본에 없는 문장' 열이 진짜 일반화 지표.
- 주문 100개는 TTS 한 목소리 + 규칙을 이 셋 오류 보고 고쳤으므로 낙관적. 진짜 확인은 실제 사람 녹음.
