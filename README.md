# sonkkeut-ai
손끝길 - 화면 꼭짓점(M1)·화면 요소(M2) 학습, 합성 데이터, 온디바이스 추론

## 김우주 담당 기능의 처리 코어

2026-10-01 「손끝길 기능 명세서」의 F-02·03·08·09(오차 계산)·10을 위한
Python 참조 구현이다. 모델이 출력한 꼭짓점·요소·손 관절을 받아 좌표 변환,
박스 정리, 손끝 평활화, 방향·도달 계산, 누름 결과 비교를 수행한다.
모델 추론이나 Android 앱을 실행하는 구현은 아직 없다.

| 기능 | 구현한 단계 | 남은 단계 |
| --- | --- | --- |
| F-02 | 네 꼭짓점 → 호모그래피·역변환, 유효성·검출 상실 처리 | M1 학습/추론, 영상 꼭짓점 추적, 이미지 펼치기 |
| F-03 | 신뢰도 필터, 종류별 NMS, 키프레임별 요소 ID | M2 학습/추론, 실제 촬영 mAP 평가 |
| F-08 | M4 관절 8번 → 화면 좌표, 최근 5개 관측 평균, 손 상실 처리 | M4 추론 어댑터, 다중 손의 실제 화면 거리 측정 |
| F-09 | 8방향 오차·거리 구간, 연속 0.3초 도달, 재인식/재시작 결정 | 임현승 담당 음성·진동 출력, 기기별 임계값 조정 |
| F-10 | 기대 화면/정확한 주문 항목 수량 대조, 1.5초 타임아웃 | F-05·07과 연결, 실제 누름·화면 전환 검증 |

Python 3.10 이상에서 추가 런타임 패키지 없이 실행할 수 있다.

```powershell
$env:PYTHONPATH = "src"
python -m unittest discover -s tests -v
python -m sonkkeut_vision.demo
```

macOS/Linux:

```sh
PYTHONPATH=src python -m unittest discover -s tests -v
PYTHONPATH=src python -m sonkkeut_vision.demo
```

데모는 만들어 둔 모델 출력값으로 처리 흐름을 재생한다. 카메라 인식 결과나
학습 모델 성능을 보여주는 데모가 아니다. 모델 가중치나 개인 영상은 커밋하지 않는다.

입출력, 조정 가능한 값, 다른 담당자와의 경계, 남은 수용 기준은
[구현 계약](docs/visual-core.md)을 참고한다.
