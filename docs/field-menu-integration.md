# 미등록 매장 현장 메뉴 · 앱 0.2.5

프론트 기본 모드를 현장 화면 인식으로 변경했다. 앱의 `ObservedMenuCatalog`가 매장 DB 없이 M2 검출 메뉴 영역의 OCR을 방문별 카탈로그로 만든다. 서로 다른 두 키프레임에서 읽기 가능하게 관찰한 이름만 등록하고, 가격 충돌/미확인은 null, 품절 표시는 후보 제외로 처리한다. 버튼·가격·옵션·장바구니 행을 실제 판매 메뉴로 추측해서 추가하지 않는다.

`MenuMatcher`는 현재 카탈로그 이름에 포함된 일반 표현(예: ‘라멘’ → 관찰된 ‘돈코츠라멘’)과 기존 음식 개념으로 **후보만** 추천한다. 공통 음식 사전은 실매장의 판매 상품 목록이 아니다. 후보 확인 후 `ScreenMenuResolver`로 현재 화면의 실제 검출 ID와 대조한다.

KoreanStructure 옵션 화면 판별에 명시적인 맵기·굽기·토핑/옵션 선택 문구를 추가했다. 옵션의 의미·그룹을 범용적으로 추론하는 모델은 아니다. 프론트가 처음 보는 버튼 글자를 번호로 읽고 사용자의 선택/완료를 확인한다. 동일 이름의 여러 위치를 임의로 골라 안내하지 않는다.

새 키오스크에서 방문 ID와 이전 주문/위치 확인을 초기화한다. 앱 재실행 시 현장 카탈로그를 복원하거나 서버로 전송하지 않는다. 등록 매장 API는 사용자가 등록 모드를 선택했을 때 사용하는 보조 경로다. 별도 AI 서버·LLM·모델 가중치 변경 없음.

전체 동작과 현재 한계는 프론트 `docs/field-kiosk-mode.md`를 참조한다. 새로운 업체/글꼴/언어/옵션 구성과 실물 카메라·마이크는 별도 검증해야 한다. 미등록 사용 구조를 제공한 것이며 모든 키오스크의 전체 기능을 보장한 결과는 아니다.
