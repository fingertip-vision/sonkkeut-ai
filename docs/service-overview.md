# 손끝길 · Fingertip Vision

손끝길은 시각장애인이 키오스크를 직접 조작할 수 있도록 돕는 Android 앱입니다. 휴대폰 카메라로 화면과 손끝을 확인하고, 원하는 메뉴까지의 방향을 음성·진동·화면 문구로 안내합니다. 사용자가 실제 키오스크를 터치하며, 앱은 화면 변화를 확인해 다음 단계를 안내합니다.

## 서비스 구성

| 저장소 | 역할 | 실행 위치 |
|---|---|---|
| [sonkkeut-frontend](https://github.com/fingertip-vision/sonkkeut-frontend) | Kotlin 앱, 카메라, 접근성 UI, 주문 확인과 안내 상태 관리 | Android 휴대폰 |
| [sonkkeut-ai](https://github.com/fingertip-vision/sonkkeut-ai) | 화면·손끝 분석, OCR, 한국어 음성 인식, 메뉴 검색, 모델 학습·평가 | 앱 안의 네이티브 모듈 / 개발 PC |
| [sonkkeut-backend](https://github.com/fingertip-vision/sonkkeut-backend) | 매장·메뉴·품절 정보, 점주 관리, 익명 사용 통계, 모델 정보 API | AWS 서버 |

## 사용 흐름

1. 앱이 서버에서 매장 메뉴를 받아 기기에 저장합니다.
2. 카메라로 키오스크 화면을 확인하고 음성 또는 직접 입력으로 주문을 준비합니다.
3. 음성을 텍스트로 바꾼 뒤 해당 매장의 메뉴 이름·별칭·관련 표현과 비교합니다. 여러 후보가 있으면 사용자가 선택하고 확인합니다.
4. 목표 버튼과 손끝 위치를 비교해 이동 방향을 안내합니다. 사용자가 직접 누른 뒤 화면 변화를 확인합니다.
5. 장바구니의 읽을 수 있는 수량·금액을 대조하고, 결제 이후 화면에 표시된 완료 문구·주문 번호를 읽습니다.

화면·음성 추론은 기본적으로 휴대폰에서 실행합니다. 영상·음성을 백엔드로 전송해 추론하는 구조가 아닙니다. Whisper 음성 모델은 첫 사용 시 GitHub 릴리스에서 별도 다운로드하며, 설치 후 기기에서 실행합니다. 백엔드는 메뉴와 운영 데이터를 제공합니다.

## 현재 개발 상태 · 2026-10-06 기준

- Kotlin 앱 0.2.3: [APK와 검증 기록](https://github.com/fingertip-vision/sonkkeut-frontend/releases/tag/v0.2.3-order-knowledge).
- 앱 기준 브랜치: `native/kotlin-20261005`, AI 기준 브랜치: `codex/unified-ai-20261003`.
- `develop_kotlin_ui_integration`은 별도의 UI 통합 개발 브랜치입니다. 기준 앱과 아직 모든 변경이 합쳐진 상태가 아닙니다.
- 프론트·AI의 `main`에는 구현이 모두 병합되지 않았습니다. 앱을 빌드할 때는 각 저장소의 실행 안내를 따르세요.
- 백엔드는 Spring Boot·MySQL을 사용하고 GitHub Actions → ECR → EC2/SSM으로 배포합니다. 현재 공개 주소는 배포 실행 요약에서 확인하세요.

## 접근성과 검증 범위

어두운 배경과 노란 버튼, 별도의 설정 화면, 고정된 안내 중지·재안내 버튼, 음성과 같은 내용을 보여 주는 화면 문구를 제공합니다. 메뉴·수량·옵션을 확인한 후 안내하며 불확실한 OCR 결과를 확정된 주문으로 취급하지 않습니다.

현재는 개발·시연 단계입니다. 합성 데이터·에뮬레이터 테스트는 실제 매장에서의 성공률을 의미하지 않습니다. 실제 한국어 마이크 입력, S26 Ultra 카메라, 큰 글자와 TalkBack, 시각장애인 사용성 및 전체 주문 과정은 추가 검증이 필요합니다. 음식 관련 표현 검색은 LLM이나 알레르기·재료 판정 기능이 아닙니다. 화면의 결제 완료 문구를 읽는 것은 금융기관의 결제 승인 조회와 다릅니다.

## 팀 개발 원칙

API·모델 출력 계약을 바꾸면 관련 저장소의 문서와 테스트도 함께 갱신합니다. 비밀키·환경 설정·실제 사용자 녹음은 커밋하지 않습니다. 브랜치별 검증 결과와 미검증 항목을 구분하고, 앱·AI 버전을 함께 기록합니다.
