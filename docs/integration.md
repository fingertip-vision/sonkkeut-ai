# 저장소 간 연동

## 실행 경로

```text
Android Kotlin 앱 ── CameraX 영상 / 마이크 입력 ── 기기 내 AI 모듈
       │                                      │
       │                           OCR·손끝·음성 텍스트·메뉴 후보
       │                                      │
       └──── 화면 표시·음성·진동·사용자 확인 ◀───┘
       │ HTTPS: 매장·메뉴 / 익명 통계 / 모델 정보
       ▼
Spring Boot API ── MySQL

GitHub AI Release ── 최초 Whisper 모델 다운로드 ── 휴대폰 앱 전용 저장소
```

## 책임과 계약

- 프론트: 카메라·마이크 권한, 세션 수명, 화면·음성 안내, 사용자 확인, 요청 취소와 오래된 결과 폐기.
- AI: 인식 결과와 신뢰도, 좌표, 후보 검색 근거를 반환합니다. 앱의 화면이나 결제 상태를 직접 변경하지 않습니다.
- 백엔드: 해당 매장의 메뉴 이름·가격·별칭·옵션·품절을 제공합니다. 실제 주문·결제 실행 API가 아닙니다.
- 메뉴 조회: `GET /api/stores/{code}/menu`. 응답의 `store_code`, `menu_version`, `items`를 사용합니다. 메뉴 버전·ETag로 갱신 여부를 판단합니다.
- 서버 응답의 정식 메뉴명·가격·품절이 기준입니다. 앱의 로컬 관련 표현 메모는 검색 보조이며 가격이나 품절을 덮어쓰지 않습니다.
- 통계: `POST /api/stats/sessions`. 서버 명세가 허용한 필드만 보냅니다. 음성·영상·위치·기기 ID를 통계 본문에 추가하지 않습니다.
- 모델 정보: `GET /api/models/latest`. 메타데이터 제공과 모델 파일 호스팅은 다릅니다. 현재 앱의 Whisper 설치기는 AI GitHub 릴리스의 고정 URL과 해시를 사용합니다.

## 안전한 안내 처리

후보가 여러 개면 질문하고 확인합니다. 인식이 불확실하면 다시 읽으며, 품절 메뉴를 유사 메뉴로 자동 교체하지 않습니다. 손끝 안내 좌표는 전체 화면 분석 좌표를 사용합니다. 상세 OCR 타일의 좌표를 전체 키오스크 좌표처럼 쓰지 않습니다. 메뉴를 못 찾으면 사용자가 스크롤·탭 전환하도록 안내하며 앱이 외부 키오스크를 원격 조작하지 않습니다.

새 매장·서버·화면으로 바뀌면 이전 결과와 확인 상태가 유효한지 검토합니다. 영상 분석은 작업 스레드에서 처리하고 CameraX 프레임은 반드시 반환합니다. 카메라 화면 이탈·백그라운드 전환·취소 시 늦게 도착한 결과로 주문을 진행하지 않습니다.

## 호환성 점검

1. 앱 커밋, AI 커밋, 모델 매니페스트, 백엔드 커밋을 기록합니다.
2. 정상 메뉴, 품절, 빈 메뉴, 404, 타임아웃, 오프라인 캐시를 확인합니다.
3. 정식 이름·별칭·관련 표현·복수 후보를 구분하고 사용자 확인을 검사합니다.
4. 실제 프레임 좌표·회전·여백·손끝 상태와 카메라 중지/재개를 확인합니다.
5. 모델 첫 설치·취소·손상 파일·재설치를 검사합니다.
6. 에뮬레이터 검증과 실물·실제 음성 검증을 분리해 기록합니다.

전체 백엔드 계약: [API 명세](https://github.com/fingertip-vision/sonkkeut-backend/blob/main/docs/api.md).
